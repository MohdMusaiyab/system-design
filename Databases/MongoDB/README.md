# 🍃 MongoDB Architecture

Welcome to the **MongoDB** deep dive. Moving completely away from rigid relational rows, MongoDB introduced the world to massively scalable, schema-less BSON document storage perfectly matching modern JSON application architectures.

## 📖 Curriculum

*(Chapters will be populated here during the module build-out)*

1.  **Document Topology:** BSON compression, schema design, and embedding vs referencing.
2.  **The WiredTiger Storage Engine:** How MongoDB writes to disk natively under extreme throughput.
3.  **High Availability:** Replica Sets, primary elections, and Oplog mechanics.
4.  **Horizontal Scale (Sharding):** Deep dive into the `mongos` router, Config Servers, and Shard Keys.
5.  **Consistency Tradeoffs:** Understanding Write Concerns (`w: majority`) and Read Concerns (`linearizable`).
