# 🐘 PostgreSQL Architecture

Welcome to the **PostgreSQL** architectural deep dive. As the world's most advanced open-source relational database, Postgres relies heavily on strict ACID compliance paradigms, complex relational modeling, and immense vertical scale capabilities.

## 📖 Curriculum

*(Chapters will be populated here during the module build-out)*

1.  **Core Storage Architecture:** Pages, Tuples, and the physics of the Postgres Heap.
2.  **Indexing Mechanics:** B-Trees, Hash Indexes, GIN, and GiST indexes mathematically explained.
3.  **Concurrency Control:** How Multi-Version Concurrency Control (MVCC) prevents read/write locks simultaneously.
4.  **Durability:** The Write-Ahead Log (WAL) and crashing recovery mechanisms.
5.  **Scaling Postgres:** Read Replicas, Logical vs Physical Replication, and Connection Pooling (PgBouncer).
