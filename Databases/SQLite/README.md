# 🪶 SQLite Architecture

Welcome to the **SQLite** architecture module. SQLite powers everything from mobile devices (iOS/Android) and web browsers to airplane flight software. It achieves this by stripping away the networking layer completely.

## 📖 Curriculum

*(Chapters will be populated here during the module build-out)*

1.  **Serverless Architecture:** The physics of an embedded database existing entirely as a single `C` library file.
2.  **Storage Mechanics:** How SQLite physically maps relational tables into a singular binary file format.
3.  **Concurrency Limits:** File-level locking, Rollback Journals vs Write-Ahead Logging (WAL mode).
4.  **Deployment Scale:** Why it is phenomenal for edge-computing and mobile, but breaks under heavy web-server concurrent writes.
